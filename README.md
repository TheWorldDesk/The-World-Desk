# The World Desk

A Next.js news portal starter for The World Desk. Includes a responsive news homepage, article detail pages, an admin dashboard preview, Tailwind CSS, and Supabase client scaffold.

## Important
The stories included are demo content, not verified reporting. The admin page is not authenticated and must not be used for real editorial work until authentication and database access policies are implemented. Multi-language routes, automatic translation, production CMS workflows, and SEO sitemap/robots configuration still need implementation.

## Run locally

```bash
npm install
npm run dev
```

## Deploy
Import this repository in Vercel and use the default Next.js settings. Configure Supabase environment variables only after creating a Supabase project. Never commit secrets or a Supabase service-role key.
